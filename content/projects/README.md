# Adding a project case study

1. Copy `_example.md` to a new file. The file name becomes the URL:
   `pa66-wire-harness-clip.md` → `www.adpolymers.in/projects/pa66-wire-harness-clip`
2. Fill in the details with real facts and numbers, and delete `draft: true`.
3. Put photos in `public/images/projects/<file-name>/` (JPG or WebP, ~1200 px wide, under 200 KB)
   and list them under `images` with descriptive alt text.
4. Commit and push. The project appears on /projects, on its industry page and in the sitemap automatically.

`industry` must be one of: automotive-plastic-components, water-filtration-components,
architectural-hardware-components, electronics-enclosures, consumer-goods.

Files starting with `_` and files with `draft: true` are never published.
